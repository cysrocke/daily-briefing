# 엘내강스

엘리베이터에서 내릴 때까지 강제 스몰토크.

그 시간을 살려 줄 기획/AI/IT 소식을 매일 아침 골라 드려요. 앱/웹/어드민을 만드는 서비스 팀이 매일 아침 보는 공개 소식 페이지예요.

- 주소: https://cysrocke.github.io/daily-briefing/
- 매일 아침 8시 전에 새 글이 올라와요. 주말/공휴일도 올라와요.

## 탭
- 직군: 서비스기획 / UI/UX 디자이너 / PM/PL/PO / 퍼블리셔 / FE 개발자 / BE 개발자 / DBA / 앱 개발자 / QA 중 내 직군을 골라 고정하면, 그 직군이 실무에서 문제를 어떻게 풀었는지 다룬 사례 글이 모여요.
- AI근황: 새 AI 모델과 서비스, 에이전트, 규제, 업무에 AI를 쓰는 방법.
- IT업계: 리테일/커머스, 앱/플랫폼 정책, 규제/보안, 빅테크/서비스 동향 소식.
- 인사이트: 매주 월요일, 지난주 글을 바탕으로 직군별 흐름과 주니어/시니어가 알아야 할 것, 해야 할 것을 정리해요.
- 행사: 국내에서 열리는 기획/디자인/개발/AI/IT 행사. 끝나는 날까지 남아요.

## 원칙
- 공개된 기사/글/영상만 모아요. 원문에서 확인한 사실만 싣고, 회사가 낸 수치는 회사 자체 평가라고 밝혀요.
- 요약과 포인트는 직접 쓴 글이고, 원문의 저작권은 각 출처에 있어요.
- 글은 7일, 인사이트는 8주 동안 볼 수 있어요.

## 파일
- index.html: 화면
- items.json: 글/행사/인사이트 데이터
- manifest.webmanifest, 아이콘: 홈 화면 바로가기
- dailypick.apk: 안드로이드 앱(스토어에 올리지 않은 개인 앱)
